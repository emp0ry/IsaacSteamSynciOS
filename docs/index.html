Features

Cloud sync with your progress in mind.

Native account, sync, backup, conflict, and log panels keep the workflow inside Isaac. Offline play remains available.

Direct Steam authentication

Sign in with QR approval in Steam Mobile or credentials and Steam Guard. Renewable session tokens are stored in the iOS Keychain.

Steam Cloud progression

Synchronize Repentance’s three progression slots and saved Continue runs with AppID 250900, including native iOS-to-Windows normalization and pair verification.

Additive achievements

After a successful manual Sync Now, add achievements unlocked in iPhone saves that remain locked on Steam. Existing Steam unlocks are preserved.

Automatic menu sync

Remote-only changes can be pulled before slot selection. Use Save and Exit, then wait for a green Steam button: stable local-only changes upload automatically.

Versioned backups

Local and remote versions are backed up before replacement, with retention and restore controls available inside the game.

Verified sync decisions

Three-way comparison detects first sync and genuine conflicts. Downloads and uploads are hash-verified before the common sync state advances.

Usage

Bring Steam progress in. Send iPhone progress back.

Startup checks apply safe remote-only updates before the game loads progression. Automatic uploads wait for stable files and the game menu; Sync Now remains available for manual sync and achievements.

Read installation guide
01

Connect your Steam account

Open the top-right Steam button from Isaac’s menu and sign in. The button and panel hide automatically during a run.

02

Choose the first save

Select Use iPhone Save, Use Steam Save, or Cancel on first sync. Both available versions are backed up before a replacement.

03

Sync after playing

Use Save and Exit and wait for the Steam button to turn green. Tap Sync Now when you also want to add missing save-derived Steam achievements.

Requirements & credits

Progression and saved runs, with verified backups.

Tested with native Isaac App Store version 1.4 and ordinary Windows Repentance in both directions. Live in-memory runs must be saved first. Repentance+ synchronization is not enabled in this release.

iOS 15 or newer

ARM64 iPhone or iPad with com.Nicalis.Isaac-iOS. Rootless and embedded installations share the same core.

Repentance saves

Each rep_persistentgamedata slot can travel with its rep_gamestate Continue snapshot. Rerun states are excluded. PC Mods Compatibility adapts the run marker, not custom mod content.

Account and network

Steam authentication and cloud operations connect directly to Valve. Offline play does not block game startup.

App signing

Back up application data before re-signing. The signing workflow can affect containers, Keychain access, receipts, and purchased DLC access.

An unofficial project, unaffiliated with Valve, Nicalis, or Apple. No game application, DLC, saves, credentials, or DRM bypass is included.
